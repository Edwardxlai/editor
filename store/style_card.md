# Style Card（暂定）

> 依据：`published_samples/` 3 篇已发布样稿，机器提取的结构证据见 `store/style_samples_raw.md`。
>
> ⚠️ **3 篇只能支撑"暂定"**。它足以证明存在一套**模板**，不足以证明这是现行**规范**，
> 更不足以推出分读者群的风格差异（PRD 假设 C3 / C4）。使用时按"参考"而非"标准"对待。

## 1. 整体版式模板（3 篇一致）

```
{标题}
内容来源：…。
责编 | X    第 {四位数} 篇深度好文：{N}字 | {M} 分钟阅读
{栏目标签}          ← 商业思维 / 商业趋势
{笔记君说：导语}    ← 可选
一、{判断句}
  1.{判断句}
    ①{要点}
…
参考资料：          ← 可选
*文章为作者独立观点，不代表笔记侠立场。
```

本工具产出的是 **v0.5 初稿**，不套用元信息行（责编、篇号、字数）——
那些是发布环节由编辑填的，AI 编造篇号只会制造假象。

## 2. 标题三型（实测归纳）

| 型 | 结构 | 样稿实例 |
|---|---|---|
| A | `人名：断言` | 梁宁：接下来，是情绪价值的比拼 |
| B | `身份/主体：警示 + 数字` | 长鑫科技，市值一度超过腾讯 |
| C | `事件 + 反差事实` | （同上，标题同时具备 B/C 特征） |

**本次素材的适配性**：逐字稿已脱敏为"嘉宾A/嘉宾B"，A 型（人名前缀）**不可用**。
角度生成只在 B/C 两型里选，或用「判断句 + 限定」的变体。

## 3. 章节标题：判断句，不是名词短语

这是 3 篇样稿最稳定、也最可迁移的一条规律。

| ✅ 判断句 | ❌ 名词短语 |
|---|---|
| 车库起家：10万美元的"芯"征途 | 公司发展历程 |
| 白牌是渠道的肥料 | 白牌与品牌的关系 |
| 效率与体验，孰本孰末 | 效率与体验 |

→ 作为 Stage 5a 的**硬约束**写进 prompt，并在 Rubric R2 里人工抽查。

## 4. 层级

`一、二、三…` → `1. 2. 3.` → `① ② ③`。
v0.5 初稿只用到前两级；第三级留给编辑扩写。

## 5. 观点表达

- 先给判断，再给论据。不做"背景铺垫 → 层层递进 → 最后揭示"的悬念式结构。
- 句子短。样稿里几乎没有超过三个逗号的长句。
- 引用嘉宾原话时用引号直引，不做转述式改写。
- 允许出现反问和口语化的过渡（"然后我们发现…"），但不允许出现无信息的过渡句。
