# README_候选人必读

## 材料包说明

本材料包用于笔记侠 FDE 加速营第二轮实战题目一。请直接阅读源文件完成方案设计和最小可运行原型；除题目说明与本 README 外，不提供额外字段字典或标准答案。

## 文件结构

```text
.
├── interview_transcript.srt
├── content_brief.md
├── historical_notes.jsonl
└── published_samples/
    ├── sample_01.docx
    ├── sample_02.docx
    └── sample_03.docx
```

## 文件说明

- `interview_transcript.srt`：脱敏后的访谈逐字稿，包含说话人与时间戳，是内容理解与证据溯源的基准输入。
- `content_brief.md`：本次内容任务的背景、目标读者、拟发布渠道、时效要求和简版编辑质量标准。
- `historical_notes.jsonl`：8 篇脱敏历史商业笔记。每行是一篇笔记，包含标题、日期、主题、正文、适用读者和可引用范围。
- `published_samples/`：3 篇脱敏已发布样稿，供候选人自行归纳内容风格。

## 重要约束

本材料包不提供原始视频或分镜稿。候选人应以 `interview_transcript.srt` 作为证据溯源基准；如认为视频信息会影响判断，请在方案假设与风险中说明。

## 脱敏声明

材料包中的人名、机构名、产品名、网站等可识别信息已做脱敏或泛化处理。材料仅用于本次面试题，不代表真实业务数据、真实采访内容或任何外部机构观点。

## 使用边界

- 请勿尝试反向识别材料中的真实人物、机构或来源。
- 可使用任意 AI 工具、开源库或低代码工具，但提交时必须标注使用的第三方代码、模型或公开素材。
- 历史笔记仅作为风格归纳、案例联想和复用判断的参考，不应未经判断直接拼接进新稿。
- 如存在素材缺失、转录含混、事实不确定、历史内容过时、适用读者不匹配或引用范围不清，请在输出中明确标注需要编辑人工确认。

## 建议输出位置

候选人可在自己的代码仓库或提交文件夹中保留运行输出，例如：

```text
outputs/
├── angles.md
├── outline.md
├── evidence.md
├── reuse_suggestions.md
├── draft_v0_5.md
└── editorial_checks.md
```
